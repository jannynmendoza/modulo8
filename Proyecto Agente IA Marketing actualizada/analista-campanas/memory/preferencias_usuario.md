# Preferencias del Usuario

## Configuración actual

- **Idioma**: Español
- **Moneda**: Euros (€)
- **Umbral del semáforo**: 20%
- **Nivel de detalle**: Resumen ejecutivo + tablas detalladas
- **Canales prioritarios**: Todos los canales disponibles
- **Formato de fecha**: AAAA-MM-DD
- **Redondeo decimal**: 2 decimales para KPIs

## Explicación de parámetros

### Umbral del semáforo (20%)
- 🟢 **Verde**: Cumple con el objetivo (desviación ≤ 20%)
- 🟡 **Amarillo**: Desviación moderada (desviación > 20% y ≤ 40%)
- 🔴 **Rojo**: Desviación significativa (desviación > 40%)

### Nivel de detalle
- **Básico**: Solo resumen ejecutivo y ranking
- **Estándar**: Resumen + tablas principales + recomendaciones
- **Completo**: Todos los detalles, incluyendo cálculos y alertas

## Cómo modificar preferencias

Para cambiar cualquier preferencia, indica al agente tu nueva configuración. Ejemplos:

- "A partir de ahora quiero el semáforo con umbral del 10%"
- "Cambia la moneda a dólares (USD)"
- "Muestra solo los 3 canales principales en el informe"
- "Quiero el nivel de detalle básico"
